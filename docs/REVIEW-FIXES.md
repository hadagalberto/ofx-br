# Independent review fixes — milestone 8

The suite was green while these defects existed, so each defect was reproduced with a
**failing-first regression test** whose expected value was derived by hand from the OFX payload,
SPEC.md, or ordinary arithmetic. No expected value was taken from the library's own output and
no snapshot was accepted without being read back and checked. No existing assertion was deleted,
skipped or loosened: the assertions that had encoded a listed bug were corrected to the right
value with a comment citing the finding.
